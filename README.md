Entrants send exactly one word their ex would use to describe them. The funniest, most painfully honest word takes the whole reward. This entry sends one word: **loading** — always loading, never finished, never delivered.

## Run it

```sh
python3 main.py
```

It writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset).
